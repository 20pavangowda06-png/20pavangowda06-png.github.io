### 2. Line Editor in C (team project)
Built with my teammate Pavan Srujan: a working command-line line editor in
C (~700 lines), compiled warning-free with `-Wall -Wextra`. It stores text
as a dynamic array of `char*` with capacity doubling, supports
insert/delete via `memmove`, and implements multi-level undo as a stack of
inverse operations. Choosing the array representation over a linked list —
after justifying that insert/delete are O(n) either way — was the key
design decision. This was my first real collaboration: small, well-tested
commits beat one giant "it works" push.
→ https://github.com/20pavangowda06-png/line-editor-
