# Pavan B S — Portfolio Blog (Activity 12)

This repo holds everything from Activity 12 — *Building Your Portfolio
Blog by Prompting an AI Assistant* (Portfolio Building B25CS0311):

| File | What it is |
|---|---|
| `index.html` | The published one-page portfolio blog (About, Projects, Skills, Contact) — this is what GitHub Pages serves |
| `brief.md` | The 1–2 page portfolio brief the page was generated from |
| `prompt-log.md` | The initial generation prompt plus every follow-up refinement prompt, with before/after notes |
| `reflection.md` | Closing reflection: which prompt helped most, and what the AI got wrong |

The page was built entirely through AI prompting (no hand-written HTML):
brief → structured prompt → generated page → review → two follow-up
refinement prompts → published. See `prompt-log.md` for the full trail.
